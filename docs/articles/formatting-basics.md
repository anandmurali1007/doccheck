# Formatting basics

This article exercises inline formatting, lists, and blockquotes.

## Inline formatting

Text can be **bold**, *italic*, or ***bold and italic***. Inline code is written
as `sync_status`, and a strikethrough looks like ~~deprecated~~.

## Unordered lists

- Connect the repository
- Choose the branch to sync
- Map the folder to a category
- Trigger the first sync

## Ordered lists

1. Create the `docs` folder at the repository root.
2. Add the `docs/.document360/assets` folder for media.
3. Place Markdown articles in a subfolder such as `docs/articles`.
4. Commit and push to `main`.

## Nested lists

- Repository setup
  - Root `docs` folder
  - Assets folder
- Portal setup
  - Connect the account
  - Select the repository
    - Pick the branch
    - Confirm the mapping

## Blockquotes

> The integration supports a one-way sync: GitHub to Document360 only.

> Content synced from GitHub is read-only in Document360.
>
> Corrections must be committed to the repository.
